# Interface languages

The player UI can be shown in **Kinyarwanda (default), English, Français, Kiswahili and Luganda**.
A visitor switches with the `RW / EN / FR / SW / LG` pills under the brand bar; the choice is
remembered in a cookie (`ihugure_lang`, one year).

This only translates the words around the quiz. **The language the questions are asked in is
a separate choice** (first screen) and still comes from the `language` table - to offer
French or Kiswahili *questions*, add those rows and the translated questions/answers to the
database as before.

## How it works

- `services/i18n.php` - language detection, the switcher, and `i18n_translate()`.
- `__('KINYARWANDA TEXT')` (already used everywhere) now looks the text up in `lang/<code>.php`.
  Kinyarwanda is the original text, so it needs no catalogue. Unknown text is shown unchanged.
- `t('key')` is used for the few interface words that are new (progress steps, 18+ note).

## Adding or fixing a text

Open `lang/en.php`, `lang/fr.php`, `lang/sw.php`, `lang/lg.php` and add `'original text, lower-case, spaces collapsed' => 'translation'`.
Write a literal percent sign as `%%` (the text goes through `sprintf`).

## Adding a language

1. Copy `lang/fr.php` to `lang/<xx>.php` (two letters) and translate every value.
2. Add the code to `i18n_languages()` in `services/i18n.php`.

The English, French, Kiswahili and Luganda texts were written without a native reviewer - please have
a speaker of each check them (especially the long rules text) before going live.

## Routing

The app has one route, `index.php`; which screen you see is kept in the session, as before.

- A language link (`?lang=fr`) saves the cookie and redirects (303) to the same address **without**
  `lang`, keeping any other query such as `?reflesh`. Refresh, Back, bookmarks and form posts therefore
  always use a clean URL, and an old shared `?lang=` link can never override a later choice.
- The browser tab/history title follows the step, e.g. `Category (3/7) · IHUGURE APP`, in the chosen language.
- There is deliberately **no URL per screen**: screen order (rules, amount, payment, questions) is
  enforced by the session, and deep links would invite skipping payment.

## The rules screen (screen 2)

`display_text()` shows a designed summary on this screen only: four fact tiles, a 3-step timeline, the
monthly-rewards note and contact pills (`ihugure_rules_summary()` in `services/ui.php`, styles in
section 14 of `assets/css/ihugure.css`). The **full original rules text is still there**, folded under
"Read the full rules". The numbers come from `LEVEL` (questions) and `TIMEOUT` (seconds); the reward
factor (200) is set in that function and must match the percentage written in the rules text. The words
are the `rl_*` entries in each `lang/<code>.php`.
